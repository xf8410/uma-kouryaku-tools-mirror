## 🧭 项目定位

对 <b>ウマ娘.攻略.tools</b>（日服赛马娘攻略站）做全量数据镜像：140 条赛道的 course_param 分段/坡道/相位数据 + 317 场赛事数据，供拉面杯模拟器与训练侧使用，自动抓取存档。

## ✨ 核心功能
- 140 赛道 course_param 全表- 317 赛事数据- 自动抓取存档，随上游更新迭代
